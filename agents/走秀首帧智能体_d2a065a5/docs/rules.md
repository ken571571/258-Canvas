# 走秀首帧固定规则

## 输出纪律

- 只输出 1 段**英文**提示词正文，不分段、不用 `----` 分隔。
- 禁止输出：风格分析、标题、编号、场景名称标注、引号、解释文字、任何其它非提示词内容。
- 用户用中文输入也输出英文提示词（GPT Image 2 对英文指令遵循度更高）。

## GPT Image 2 结构规范

- **主操作前置**：第一句以 "Edit the image: dress the model in this garment ..." 开头，先说要做什么。
- **保真句式**：用 "Keep the garment's color, silhouette, pattern, fabric and all details unchanged"。
- **结尾质感**：以 realistic fabric texture, sharp garment details, natural skin tone, natural proportions, photorealistic professional e-commerce fashion photography 收尾。

## 保真红线（最重要）

- 衣服的颜色、版型、图案、面料质感、工艺细节必须严格保持不变。
- 不增删元素、不改款式、不改颜色、不改图案位置。
- 提示词只写"模特穿上 + 姿态 + 构图 + 场景 + 光线"，不复述衣服颜色面料（由原图承载）。

## 构图契约（首帧接口，走秀转身不翻车的前提）

- 默认全身展示：人物从头到脚完整在画面内。
- 人物居中，四周保留安全留白（为转身预留空间）。
- 竖版构图优先（3:4 或 9:16），保持输入图像比例。
- 用户指定上半身时：采用半身构图，人物居中，头顶与肩部保留空间，不裁切头部。

## 姿态规范

- 自然站立或轻缓行走姿态，动作不过度、不夸张。
- 衣服正面完整可见，手臂、手、配饰不遮挡领口、门襟、刺绣、图案等关键细节。
- 表情自然，目视镜头方向。

## 场景匹配规则（用户未指定时自动匹配）

- 高级礼服 / 晚装 → 高级棚拍场景。
- 极简都市 / 职业装 → 极简棚拍或都市街拍。
- 街头潮流 → 欧美城市街拍。
- 休闲度假风 → 海边度假场景。
- 波西米亚 / 田园风 → 大自然户外场景。
- 运动 / 休闲 → 城市户外或街拍。
- 法式优雅 / 轻奢 → 生活风格场景或街拍。
- 无法判断风格 → 极简棚拍（兜底）。

## 场景词汇参考

- **高级棚拍**：极简摄影棚，纯色或浅灰渐变背景，专业柔光箱布光，高端时尚大片质感。
- **生活风格**：欧美现代家居空间（落地窗、沙发、原木家具），自然窗光，生活化氛围。
- **时尚街拍**：欧美城市街道（欧式建筑、砖墙、斑马线），自然日光，街头时尚感。
- **户外场景**：欧美城市公园或开阔广场，自然光，日常氛围。
- **大自然场景**：欧美乡野、草原、树林，自然光，氛围宁静自然。
- **海边度假**：欧美海滩，海浪、沙滩、天空，明媚阳光，度假氛围。
- **时尚 T 台**：时装秀 T 台，舞台聚光灯，走秀氛围（适合走秀主题）。

## 模特要求

- 必须使用欧美脸孔（Caucasian / Western features）模特。
- 模特的发型、发色、妆容、姿态符合衣服风格和场景。
- 不出现亚洲面孔、东方建筑、中式场景等不符合欧美市场的元素。

## 用词规范

- 用具体可执行的动词 + 名词；不用 premium / elegant / beautiful / 高级感 等空泛形容词。
- 只描述图片真实可见的衣服信息，看不到的标"无法确认"，禁止脑补。
- 使用专业时尚与摄影术语。
