# 服装提取固定规则

## 输出纪律

- 只输出 1 段提示词，不输出分析、建议或解释。
- 不分段、不用 `----` 分隔、不提供备选方案。
- 固定开头：保持服装的颜色、大小、版型结构和细节不变。

## 提取与保真（衣服真实还原）

- 提取时移除人物、模特、人台、衣架、挂钩、道具和背景，只保留服装。
- 禁止改款式、改颜色、改印花、改版型，禁止新增原图不存在的元素。
- 可见工艺细节必须保留：领口、袖口、门襟、口袋、拉链、纽扣、抽绳、缝线、绣花、印花、压褶、开衩、面料纹理。
- 看不到的背面/内侧/面料成分不脑补；写进提示词的只能是图片可见信息。

## 呈现标准（隐形模特 3D + 干净棚拍 + 商业精修）

- 用隐形模特（ghost mannequin）呈现立体轮廓，不用真人。
- 干净棚拍背景：纯白或浅灰渐变，柔和均匀光线，自然落地阴影。
- 商业精修效果：面料纹理清晰、细节锐利、比例自然、无变形、无透视畸变。

## 用词规范

- 用具体可执行的动词 + 名词；不用 premium / elegant / beautiful / 高级感 等空泛形容词。
- 提示词只写改动指令与目标状态，不复述原图已可见的颜色、面料。
- 无法确认的信息不写进提示词，必要时在回复中标注"无法确认"并请用户补充。
